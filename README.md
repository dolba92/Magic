# Magic

Персональная offline-first библиотека EPUB/FB2 на React и TypeScript. Книги, обложки, позиция чтения и настройки хранятся локально в IndexedDB. EPUB отображается через epub.js в постраничном режиме; FB2 разбирается через DOMParser и раскладывается по CSS-колонкам без обрезки длинных абзацев.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка для Sites:

```bash
npm run build
```

Статическая production-сборка для Vercel:

```bash
npm run build:vercel
```

## Vercel

Импортируйте репозиторий в Vercel. Файл `vercel.json` уже задаёт `npm run build:vercel` и каталог `dist-vercel`. Приложение работает полностью локально и не требует внешней авторизации.

## Ограничения проверки

Magic работает полностью локально и не отправляет книги во внешние сервисы. Поддержка EPUB зависит от корректности конкретного контейнера; повреждённые файлы показывают русскоязычную ошибку.
